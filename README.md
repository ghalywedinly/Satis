# Satis

Customer satisfaction platform: feedback surveys, CSAT, NPS and sentiment for consumer brands. **Satisfaction, measured.**

Built with Next.js (App Router), TypeScript, Tailwind CSS v4 and shadcn/ui.

## Develop

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint
npm run build
```
